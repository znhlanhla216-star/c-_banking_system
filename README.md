# c-_banking_system
A  c++ program for a banking system for 3 account holders
GCC Banking System
Introduction to Programming – NQF 4
About the Project
This project is a basic banking system developed using C++. It was created as part of my Introduction to Programming assignment at Gauteng City College.
The program allows three registered account holders to perform basic banking activities through a command-line menu.
Features

User login using an account number and PIN.
Deposit money.
Withdraw money.
Send cash to another registered account.
Check account balance.
Input validation.
